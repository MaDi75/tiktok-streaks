# 🔥 TikTok Streaks

Десктоп-приложение для Windows, которое помогает не терять серии (огоньки) в личных сообщениях TikTok.

> ⚠️ Неофициальный проект, никак не связан с TikTok / ByteDance. Приложение управляет веб-версией TikTok
> от твоего имени — это может противоречить правилам TikTok. Используй на свой страх и риск.

![](src-tauri/icons/128x128.png)

## Что умеет

- **Список чатов** с аватарками и поиском — отмечаешь 🔥 тех, с кем у тебя серия.
- **Отправить всем одной кнопкой** или каждому по отдельности (➤). Общее сообщение или своё для каждого человека (эмодзи / текст).
- **Авто-отправка каждый день** в выбранное время; не шлёт повторно тем, кому уже отправлено сегодня.
- **Защита серии** — в выбранное время проверяет, кто тебе сегодня ответил, и предупреждает, если серия под угрозой.
- **Telegram-бот** — уведомления и команды с телефона: `/status`, `/send`, `/send имя`, `/check`.
- **Самопроверка** — если TikTok поменял сайт, покажет, что именно сломалось. CSS-селекторы можно поправить прямо в настройках.
- Живёт в трее, запускается вместе с Windows, окно браузера прячется за край экрана.
- Лёгкое: ~30 МБ памяти, установщик ~2.5 МБ (Rust + Tauri).

## Установка

1. Скачай `TikTok Streaks_x.y.z_x64-setup.exe` из [Releases](../../releases) и установи.
2. Нажми **«Показать браузер»** — откроется отдельное окно Microsoft Edge. Войди там в свой TikTok (один раз).
3. Нажми **«↻ Обновить список»**, отметь 🔥 нужных людей, выбери время.
4. Поставь галочку **«Запускать вместе с Windows»**.

Нужен Windows 10/11 и Microsoft Edge (есть по умолчанию) или Google Chrome.

### Telegram-бот (по желанию)

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи токен.
2. В приложении: карточка «Telegram-бот» → вставь токен → «Сохранить».
3. «Получить код привязки» → отправь своему боту `/start КОД`.

Бот слушается только привязанный чат.

## Где хранятся данные

Всё хранится **только у тебя на компьютере**:

- настройки, список чатов, история, токен бота — `%APPDATA%\local.tiktokstreaks.desktop\config.json`
- вход в TikTok — отдельный профиль Edge в `%APPDATA%\local.tiktokstreaks.desktop\browser-profile`

Приложение никуда не отправляет данные, кроме самого TikTok и (если настроен) твоего Telegram-бота.

## Как это работает

У TikTok нет публичного API для личных сообщений, поэтому приложение запускает Edge с отдельным профилем
и управляет страницей `tiktok.com/messages` через Chrome DevTools Protocol (порт 9333): читает список чатов,
открывает нужный, вставляет текст и нажимает Enter. Перед отправкой проверяет, что открыт чат именно с этим человеком.

```
src/                 интерфейс (HTML/CSS/JS)
src-tauri/src/
  main.rs            команды, трей, отправка, защита серии
  browser.rs         запуск Edge и минимальный CDP-клиент
  tiktok.rs          работа со страницей сообщений, селекторы
  telegram.rs        Telegram-бот (long polling)
  scheduler.rs       ежедневные задачи
  store.rs           настройки (config.json)
```

## Сборка из исходников

Нужны [Rust](https://rustup.rs), [Node.js](https://nodejs.org) и
[Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) с компонентом «Разработка классических приложений на C++».

```bash
npm install
npm run dev      # запуск в режиме разработки
npm run build    # установщик появится в src-tauri/target/release/bundle/nsis/
```

<details>
<summary>Без Visual Studio (через MinGW)</summary>

```bash
rustup toolchain install stable-x86_64-pc-windows-gnu
winget install BrechtSanders.WinLibs.POSIX.UCRT   # gcc + dlltool, добавить mingw64\bin в PATH
rustup override set stable-x86_64-pc-windows-gnu
```

MinGW не любит кириллицу в путях — держи проект в папке с латинскими буквами (например `D:\dev\TikTokStreaks`).
</details>

## Если что-то сломалось

TikTok время от времени меняет сайт. Нажми **🩺 Самопроверка** — пункт с ✗ подскажет, какой селектор устарел.
Исправить можно в «Для продвинутых: селекторы сайта» (открой tiktok.com/messages, F12, найди элемент и его `data-e2e`).
PR с исправленными селекторами приветствуются.
