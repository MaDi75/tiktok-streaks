# Сервер анонимной статистики

Простой приёмник «пингов» от приложения TikTok Streaks. Нужен, только если ты
хочешь видеть, сколько людей пользуется приложением и из каких регионов (по IP).

**Статистика добровольная:** приложение ничего не отправляет, пока пользователь
сам не включит переключатель в настройках и не укажет адрес этого сервера.

## Что приходит

На каждый `POST /ping` сервер записывает строку в `pings.jsonl`:

```json
{"time":"2026-11-20T18:00:00.000Z","ip":"1.2.3.4","installId":"a1b2…","version":"0.2.0","os":"windows"}
```

- `ip` — адрес соединения (так сервер и «видит» географию пользователей);
- `installId` — случайный анонимный идентификатор установки (не привязан к личности);
- `version`, `os` — версия приложения и тип ОС.

Сообщения, имена контактов и аккаунт TikTok **не** передаются.

## Запуск

```bash
node server.js            # порт 8787
PORT=3000 node server.js  # другой порт
```

Эндпоинты:
- `POST /ping` — приём статистики (сюда указывает приложение);
- `GET /stats` — сводка: всего пингов, уникальных установок, уникальных IP.

## Как подключить приложение

1. Разверни этот сервер на своём хостинге (VPS, Railway, Render и т. п.),
   желательно за HTTPS. Получится адрес вида `https://твой-домен/ping`.
2. В приложении открой карточку **«Статистика использования»**, включи галочку
   и вставь этот адрес.

## Важно про закон

IP — персональные данные. Если приложением пользуются люди из ЕС/ЕЭЗ, по GDPR
нужно: собирать только с согласия (здесь — явная галочка, по умолчанию выкл),
описать это в политике конфиденциальности и не хранить дольше, чем нужно.
Галочка и честный текст в приложении — это необходимый минимум; политику
конфиденциальности добавь, если будешь распространять приложение широко.
